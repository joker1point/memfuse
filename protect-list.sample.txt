# memfuse / memory-guard 保护名单样本
#
# 用法：把本文件复制为 protect-list.txt（默认路径：脚本同目录），每行写一个进程名。
# 大小写不敏感，.exe 后缀可省略，# 开头为注释。
# 写在这里的进程永远不会被守护终止。
#
# 注意：脚本已硬保护 45 项"系统关键进程"（内核/会话、OS 基础设施、安全软件），
# 那些不需要你操心。这里只需要补你自己在意的应用进程 —— 但代价要清楚：
# 被你保护的进程，也可能正是内存跌到临界时最大的那一个占用者。

# --- 示例：不希望被打断的长任务 ---
# node
# python
# code

# --- 示例：把同步/备份看得比"保住机器"更重时 ---
# OneDrive.Sync.Service
